# GitHub Issue Templates for Testing

This directory contains standardized GitHub issue templates for comprehensive test planning and execution following ISTQB and ISO 25010 standards.

## Template Structure

### Core Test Planning Templates
- `test-strategy-template.md` - Overall testing approach and quality validation plan
- `qa-plan-template.md` - Quality assurance validation and ISO 25010 assessment
- `playwright-test-template.md` - End-to-end test implementation using Playwright

### Test Type Templates
- `unit-test-template.md` - Component-level testing template
- `integration-test-template.md` - Interface and interaction testing template
- `performance-test-template.md` - Non-functional performance validation template
- `security-test-template.md` - Security requirement and vulnerability testing template
- `accessibility-test-template.md` - WCAG compliance and inclusive design validation template

### Usage Guidelines

1. **Template Selection**: Choose the appropriate template based on the test type and scope
2. **Customization**: Adapt the template to specific feature requirements and context
3. **Labeling**: Apply consistent labels as specified in each template
4. **Estimation**: Use the estimation guidelines provided in each template
5. **Dependencies**: Document dependencies clearly using the template structure

### Quality Standards

All templates enforce:
- ISTQB test design technique selection
- ISO 25010 quality characteristic assessment
- Risk-based testing prioritization
- Comprehensive acceptance criteria definition
- Clear definition of done statements
