# Ways of Work Documentation

This directory contains the comprehensive test planning and quality assurance framework based on ISTQB and ISO 25010 standards.

## Structure

- `plan/` - Contains feature-specific planning documentation
  - `{epic-name}/` - Epic-level organization
    - `{feature-name}/` - Feature-specific documentation
      - `test-strategy.md` - ISTQB-based test strategy
      - `test-issues-checklist.md` - GitHub issues planning
      - `qa-plan.md` - ISO 25010 quality assurance plan
      - `technical-breakdown.md` - Technical implementation details
      - `implementation-plan.md` - Development implementation plan
      - `project-plan.md` - GitHub project management plan

## Framework Standards

- **ISTQB Framework**: Test process activities, design techniques, types, and risk-based testing
- **ISO 25010 Quality Model**: Quality characteristics validation and measurement
- **GitHub Integration**: Issue templates and project management aligned with testing processes

## Usage

1. Create epic and feature directories under `plan/`
2. Use the provided templates to create comprehensive test documentation
3. Generate GitHub issues using the standardized templates
4. Follow quality gates and validation processes

See individual template files for detailed guidance on implementation.
